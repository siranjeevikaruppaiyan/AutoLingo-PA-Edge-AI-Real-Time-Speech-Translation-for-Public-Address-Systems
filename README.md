AutoLingo-PA: Edge-AI Real-Time Speech Translation for Public Address Systems

Project Description:

AutoLingo-PA is an Edge-AI-based system designed to translate public announcements into multiple languages in real time, including offline operation.

Objectives

- Support multilingual public announcements.
- Reduce language barriers in public places.
- Improve accessibility and emergency communication.
- Integrate with existing Public Address (PA) systems.

System Architecture

Microphone Input → Speech Recognition → Machine Translation → Text-to-Speech → PA System Output

Target Locations

Railway stations, hospitals, bus terminals, colleges, and other public spaces.

Key Features

- Offline processing (planned prototype feature)
- Multilingual translation
- Low-latency announcement delivery
- Emergency announcement prioritisation

Development Status

Prototype concept and architecture documentation. Implementation and testing are in progress.
